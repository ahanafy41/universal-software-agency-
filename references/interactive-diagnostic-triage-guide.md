# Interactive Diagnostic Triage Guide

Protocol for conducting interactive turn-by-turn discovery during bug diagnosis.

## Probing Sequence (One Question Per Turn)
1. **Trigger Action**: "What exact action, button click, or command caused the failure?"
2. **Environment**: "What operating system, runtime, and SDK version are you using?"
3. **Behavior Discrepancy**: "What was the expected output versus the actual behavior/error message?"
4. **Log Data**: "Do you have relevant console output, logs, or stack traces?"
