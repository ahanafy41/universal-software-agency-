# Standard Architecture Blueprints & 3-Tier Guidelines (المعايير المعمارية وهياكل الملفات القياسية)

Provides standardized directory structures, naming conventions, 1-click execution scripts, and **Universal Accessibility (Keyboard-First / Screen-Reader friendly)** standards for major supported technology stacks.

---

## 1. ♿ Universal Accessibility (A11y) & Keyboard-First Architecture Standards

All UI, Desktop, and CLI applications generated by the agency must conform to these universal accessibility invariants:

### A. Web & UI Applications (React / TypeScript / HTML)
- **Semantic HTML First**: Always use `<main>`, `<nav>`, `<header>`, `<footer>`, `<section>`, `<button>`, `<input>`, `<dialog>`. Never use clickable `<div>` or `<span>` without ARIA role and keyboard handlers.
- **Full Keyboard Navigation**:
  - All interactive elements must be focusable via `Tab` / `Shift+Tab`.
  - Buttons and interactive items must handle `Enter` and `Space` keys.
  - Modals and dialogs must trap focus, close on `Escape`, and return focus to the trigger element upon closing.
  - Visual focus indicators (e.g. `focus-visible:outline-2 focus-visible:outline-offset-2`) must never be suppressed.
- **ARIA & Screen-Reader Compatibility**:
  - Provide explicit `aria-label` or `aria-labelledby` for icon buttons, inputs, and custom widgets.
  - Use `aria-live="polite"` or `aria-live="assertive"` for dynamic status updates, toast messages, and loading alerts.
- **Color Contrast**: Enforce WCAG AA compliant contrast ratio (minimum 4.5:1 for normal text).

### B. Desktop Applications (C# WPF / WinForms / Python GUI)
- **Accelerators & Mnemonics**: Add keyboard shortcuts for all menu items and primary actions (e.g. `&File`, `&Save`, `Ctrl+S`, `Ctrl+N`).
- **Logical Tab Order**: Explicitly set `TabIndex` on all input controls following the natural visual/logical flow.
- **Automation Properties**: Set `AutomationProperties.Name` and `AutomationProperties.HelpText` (WPF) or `AccessibleName` and `AccessibleRole` (WinForms).

### C. CLI & Terminal Applications (Python / Rust / Go / C#)
- **Structured Text Output**: Clean, deterministic console output avoiding flashing raw ANSI escapes.
- **Screen-Reader Friendly Tables**: Clean formatted text headers and structured row separators.
- **Accessible Flags**: Provide `--json` for machine/screen-reader ingestion and `--plain` for unadorned text.

## 2. Standard Tech Stack Directory Layouts

### 1. Python 3-Tier Architecture Layout
```text
my_python_project/
├── core/
│   ├── __init__.py
│   ├── domain_models.py
│   └── business_service.py
├── data/
│   ├── __init__.py
│   ├── database_context.py
│   └── local_store.py
├── ui/
│   ├── __init__.py
│   ├── cli_view.py
│   └── accessible_dashboard.py
├── tests/
│   ├── __init__.py
│   ├── test_core.py
│   └── test_data.py
├── run.sh
├── run.bat
├── pyproject.toml
└── main.py
```
