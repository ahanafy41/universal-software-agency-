An enterprise-grade protocol empowering the Lead Orchestrator and **ALL specialized worker subagents** to proactively leverage **Google Search**, live official SDK documentation, GitHub repositories, and developer ecosystems for cutting-edge, professional, and up-to-date (2026) software engineering solutions.

## 1. 🌐 Universal Live Search Mandate for ALL Subagents (التفويض الإلزامي للبحث المباشر لجميع الوكلاء)

To guarantee that the agency never generates hallucinated or deprecated code based on outdated static memory:
1. **Mandatory Live Verification in 2026**: Whenever any subagent designs an architecture, selects a library, integrates an API, authors unit tests, or diagnoses a compiler error, it **MUST proactively query Google Search / web documentation** to obtain the official 2026 API signatures, version compatibility, and breaking changes.
2. **Zero-Guessing Invariant**: Never guess function parameters, method names, or class namespaces of third-party libraries or modern framework versions (e.g. .NET 8/9/10, Python 3.12/3.13/3.14, React 19, Node.js 22/24, Rust 2024 edition, Go 1.22+).
3. **Cross-Agent Search Integration**:
   - **Subagent A (Knowledge & Specs)**: Searches for official JSON schemas and RFC specifications.
   - **Subagent C (Developers - UI/Core/Data)**: Searches for official 2026 API references, modern syntax, and recommended patterns.
   - **Subagent D (Testing Engineer)**: Searches for modern test runner APIs and mock library conventions.
   - **Subagent E (Diagnostics Specialist)**: Searches exact error strings and stack traces on GitHub Issues and StackOverflow to find verified root causes.
   - **Subagent G (Dedicated Research Specialist)**: Performs deep architectural benchmarks and non-traditional pattern discovery.
   - **Subagent H (DevOps & Packaging)**: Searches for base container tags, Dockerfile best practices, and GitHub Actions versions for 2026.

## 2. High-Precision 2026 Search Query Strategies (صيغ واستراتيجيات البحث الدقيق لعام 2026)

### 📌 1. Official Documentation Lookups
Target authoritative sources with domain scoping:
* **C# / .NET**: `site:learn.microsoft.com "C# 12" OR "C# 13" "exact_api_name"`
* **Python**: `site:docs.python.org/3/ "exact_module_name"` OR `"FastAPI" "2026" "pydantic v2"`
* **TypeScript / Web**: `site:developer.mozilla.org OR site:react.dev "exact_feature"`
* **Rust**: `site:docs.rs OR site:doc.rust-lang.org "crate_name"`
* **Go**: `site:pkg.go.dev "package_path"`

### 🔍 2. Obscure Error & Stack Trace Forensics
When encountering cryptic runtime exceptions or compiler rejections:
* Search exact compiler error codes (e.g., `CS8602 "dereference of possibly null reference"` or `E0382 "borrow of moved value"`).
* Query GitHub Issues: `site:github.com "library_name" "exact_error_message" "is:issue"`.

### ⚡ 3. 2026 Deprecations and Breaking Changes
* Query: `"[framework/library]" "breaking changes" "2025 OR 2026" OR "migration guide"`.
* Verify that APIs replaced in recent versions are avoided.
