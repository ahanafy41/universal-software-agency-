# Automated Multi-Language Testing Frameworks Guide (دليل هندسة الاختبارات الآلية الشامل)

Standardized testing protocols, assertions, and mock structures across all supported technology stacks to enforce the **Zero-Flakiness Invariant**.

---

## 1. The Arrange-Act-Assert (AAA) Testing Standard

Every automated test generated by **Subagent D** must follow the explicit AAA pattern:
1. **Arrange**: Set up fixtures, inputs, and mocked dependencies.
2. **Act**: Invoke the single method or function under test.
3. **Assert**: Verify the return value, state change, or thrown exception deterministically.

---

## 2. Polyglot Testing Standards

### 🐍 1. Python (`pytest`)
```python
import pytest
from core.business_service import calculate_discount

def test_calculate_discount_valid_percentage():
    # Arrange
    original_price = 100.0
    discount_pct = 20.0

    # Act
    final_price = calculate_discount(original_price, discount_pct)

    # Assert
    assert final_price == 80.0

def test_calculate_discount_invalid_percentage_raises():
    # Arrange & Act & Assert
    with pytest.raises(ValueError):
        calculate_discount(100.0, 150.0)
```

### 🔷 2. C# .NET (`xUnit` + `FluentAssertions`)
```csharp
using Xunit;
using FluentAssertions;
using MyProject.Core.Services;

public class DiscountServiceTests
{
    [Fact]
    public void CalculateDiscount_WithValidInput_ReturnsDiscountedPrice()
    {
        // Arrange
        var service = new DiscountService();

        // Act
        var result = service.CalculateDiscount(100m, 20m);

        // Assert
        result.Should().Be(80m);
    }
}
```

### 🟨 3. TypeScript / JavaScript (`Vitest` / `Jest`)
```typescript
import { describe, it, expect } from 'vitest';
import { calculateDiscount } from '../src/core/discount';

describe('Discount Calculator', () => {
  it('calculates correct discounted price', () => {
    // Arrange
    const price = 100;
    const discount = 20;

    // Act
    const result = calculateDiscount(price, discount);

    // Assert
    expect(result).toBe(80);
  });
});
```

### 🦀 4. Rust (`cargo test`)
```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_calculate_discount() {
        // Arrange
        let price = 100.0;
        let discount = 20.0;

        // Act
        let result = calculate_discount(price, discount).unwrap();

        // Assert
        assert_eq!(result, 80.0);
    }
}
```

### 🔵 5. Go (`testing` package)
```go
package core_test

import (
	"testing"
	"my_go_project/internal/core"
)

func TestCalculateDiscount(t *testing.T) {
	// Arrange
	price := 100.0
	discount := 20.0

	// Act
	result, err := core.CalculateDiscount(price, discount)

	// Assert
	if err != nil {
		t.Fatalf("unexpected error: %v", err)
	}
	if result != 80.0 {
		t.Errorf("expected 80.0, got %f", result)
	}
}
```
