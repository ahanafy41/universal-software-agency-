منظومة برمجية مؤسسية مستقلة بنسبة 100% (**Zero External Dependencies**) ومبنية بهندسة خماسية رشيقة فائقة السرعة (**5-File Lean Architecture**). مصممة لتمكين المبتدئين وغير المبرمجين إلى جانب كبار المطورين من بناء برمجيات قوية عبر **حوار عصف ذهني سقراطي مستمر**، وتطبيق **قاعدة الـ 100 سطر للملفات**، واختبار المنطق ميكانيكياً بنسبة 100% عبر كافة المنصات ولغات البرمجة (Python, TypeScript, Go, Rust, C#, Java, Shell, Lua).

> **المبدأ الفولاذي الأساسي**:  
> **مخالفة حرفية القواعد هي مخالفة لروحها؛ لا يُقبل أي التفاف أو تجاوز بدعوى السرعة أو المرونة.**  
> *(Violating the letter of the rules is violating the spirit of the rules).*

## 🌟 الركائز الأساسية للإصدار الرابع الرشيق (v4.0)

1. **الاستقلالية التامة (Zero External Dependencies)**:
   - مهارة قائمة بذاتها بالكامل؛ لا تحتاج أي مهارة إضافية، وتعمل بنظام التشغيل الفوري (Zero-Config).
2. **العصف الذهني السقراطي الدائم**:
   - حوار مستمر مع المستخدم في كل مرحلة (سؤال إلى سؤالين بخيارات واضحة باللغة العربية)، وتوثيق دائم للقرارات على القرص في `BRAINSTORMING.md` و `DECISIONS.md`.
3. **قاعدة الـ 100 سطر الصارمة للملفات**:
   - حظر تام لأي ملف كود يتجاوز 100 سطر كود لضمان تقسيم الكود إلى وحدات معمارية صغيرة وسهلة القراءة ومريحة لقارئات الشاشة وتمنع كسل النماذج الصغيرة.
4. **فحص المنطق والـ Assertions الميكانيكي**:
   - حظر الاكتفاء بفحص السنتاكس؛ تشغيل حقيقي للاختبارات وتأكيد صحة المعادلات والنتائج بالأرقام والـ `assert` بنسبة 100% نجاح.
5. **بوابة التصحيح الذاتي الصامتة (3-Strike Self-Healing)**:
   - في حالة فشل أي فحص، ينفذ الوكيل ذاتياً حتى 3 محاولات صامتة لعزل السبب الجذري والإصلاح وإعادة الفحص قبل إزعاج المستخدم.
6. **استمرارية الجلسات والذاكرة الثابتة (`tasks.md`)**:
   - تتبع دقيق للمهام بمربعات `[ ]` و `[x]` ومؤشر `👉 CURRENT TASK` لضمان إكمال المشاريع الكبيرة عبر الجلسات دون فقدان للذاكرة.
7. **التسليم السهل لغير المبرمجين (Smart Auto-Venv Runner)**:
   - سكريبت تشغيل ذكي بنقرة واحدة (`run.sh`/`run.bat`) ينشئ البيئة الافتراضية تلقائياً ويثبت التبعيات ويدعم الفحص الذاتي (`--doctor`).

## 🛡️ جدول إفحام المبررات (Rationalization Table)

| المبرر أو حيلة الالتفاف | الحقيقة الهندسية الصارمة والرد الإلزامي |
| :--- | :--- |
| *"الملف 105 أسطر بس وفصله صعب"* | الفاحص الميكانيكي سيسقطه فوراً بـ `[ModularBloatViolation]`. افصل المسؤوليات فوراً؛ لا استثناء لسطر واحد. |
| *"السنتاكس سليم والـ AST مر"* | السنتاكس يمر حتى لو الدالة ترجع `None` أو معادلة خاطئة. لا اعتماد بدون `assert` حقيقي يجتاز `--run-tests`. |
| *"المستخدم مستعجل فهكتب كود علطول"* | التسرع يضمن إعادة كتابة الكود لاحقاً وضياع ساعات. سؤالان سقراطيان محكمان يوفران وقتاً هائلاً. |
| *"هسيب TODO والمستخدم هيكمله"* | المستخدم قد يكون غير مبرمج أو كفيف؛ ترك كود ناقص خيانة للأمانة. الكود يُسلَّم كاملاً 100%. |
| *"العطل واضح وهصلحه فوراً بدون إثبات"* | الترقيع بدون إثبات مصغر (Reproduction First) يخلق أعطالاً جانبية صامتة. اثبت العطل أولاً ثم أصلحه. |
| *"مش محتاج نسخة احتياطية"* | أي تعديل بدون `backup_manager.py backup` مخاطرة ممنوعة. النسخ يستغرق 0.1 ثانية فقط. |

## 🚩 علامات الخطر (Red Flags)

- الشروع في كتابة أي كود قبل طرح السؤال السقراطي وتوثيقه في `BRAINSTORMING.md`.
- ملف يتجاوز 100 سطر كود لأي مبرر كان.
- وجود كلمة `TODO` أو `FIXME` أو أكواد مقتطعة `... rest of code`.
- الادعاء بأن "الكود يعمل" بمجرد قراءة الكود بالعين دون تشغيل `--run-tests` بنجاح 100%.
- تعديل كود لعلاج كراش دون إنشاء سكريبت مصغر يثبت الكراش مسبقاً.

## ⚡ التشغيل والاستخدام

المهارة تعمل فوراً بمجرد نسخها إلى مجلد المهارات:
- فور طلب أي مهمة برمجية، يطلق الوكيل جلسة العصف الذهني الاستكشافية فوراً.
- يتم إنشاء ملفات `BRAINSTORMING.md` و `DECISIONS.md` و `tasks.md`.
- ينفذ الوكيل الكود خطوة بخطوة، مع نسخ احتياطي لحظي، وبكود لا يتجاوز 100 سطر للملف.
- يتم تشغيل الفاحص الشامل:
  ```bash
  python3 scripts/validate_code.py --strict --human-grade --run-tests .
  ```
- لا يُعتمد الكود إلا بعد ظهور: `[PASS] All behavioral and assertion tests passed 100%!`.
